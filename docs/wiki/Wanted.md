# Wanted Functionality

The version-controlled [WANTED.md](https://github.com/MartinGroh/Codex-Architecture-Visualizer-Engine/blob/main/WANTED.md) is the canonical list. It currently invites work on cross-platform packaging, provider conformance, architecture history, privacy-filtered review bundles, impact analysis, accessibility, large-graph performance, end-to-end demo tests, production plugin delivery, and a stable extension contract.

Open an issue before implementation so a maintainer can confirm scope, owner, privacy boundary, and compatibility expectations.
