# CAVE brand asset provenance

The CAVE mark is an original project asset created on 2026-08-23. It depicts a compact directional dependency flow and was not copied or derived from an icon library, company mark, or other third-party artwork.

`cave-icon.svg` is the editable source. `cave-icon.png` is its 512 × 512 plugin-package render. Both are distributed under the repository's MIT license.

Lucide remains in use for generic interface and architecture semantics, but no Lucide glyph is used as the CAVE product identity.
