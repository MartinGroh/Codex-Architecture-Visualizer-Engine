# Contributing

CAVE welcomes focused issues and pull requests that preserve its architecture and privacy model.

1. Read [CONTRIBUTING.md](https://github.com/MartinGroh/Codex-Architecture-Visualizer-Engine/blob/main/CONTRIBUTING.md), the [Code of Conduct](https://github.com/MartinGroh/Codex-Architecture-Visualizer-Engine/blob/main/CODE_OF_CONDUCT.md), and the [architecture guidelines](https://github.com/MartinGroh/Codex-Architecture-Visualizer-Engine/blob/main/ArchitectureAndCodeGuidlines.md).
2. Open a design issue before changing a service boundary, storage, protocol, provider, public contract, or privacy default.
3. Develop against the explicit synthetic demo when possible.
4. Run focused tests, both stack builds, and the public-readiness audit.
5. Complete the pull-request template with verification and privacy impact.

See the canonical [Wanted list](https://github.com/MartinGroh/Codex-Architecture-Visualizer-Engine/blob/main/WANTED.md) for contribution ideas.
