# Changelog

All notable changes are recorded here. CAVE follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Open-source collaboration, governance, wiki, release, security, and issue templates.
- An explicit, fully synthetic demo composition with reproducible screenshots and walkthrough videos.
- Public-readiness and branch-protection automation.
- A writable semantic engineering workspace with shared diagram and Kanban identities, atomic revision-checked batches, and session undo/redo.
- Trusted-network exact-task chat delivery and isolated node answers, plus machine activity and recent-work views.
- Shared public-chat rendering for Codex writing-block attributes, code comments, chat markers, suggested follow-ups, citation references, Markdown tables, and task lists.

### Fixed

- Codex 0.157 contract handling for interruption, ephemeral forks, server requests, and missing usage metrics.
- Reported frontend dependency vulnerabilities through compatible patch updates.
- Multi-step semantic undo/redo, positioned-entity deletion, malformed write payload rejection, activity provenance labels, and the mobile focused-work empty state.

## [0.3.0] - 2026-08-19

### Added

- Local-first Codex architecture visualization with system-to-class semantic projections.
- Native Git delta, live agent activity, opt-in conversation, and Codex usage overlays.
- Embedded MCP App, read-only browser viewer, local plugin installer, and verification pipeline.
